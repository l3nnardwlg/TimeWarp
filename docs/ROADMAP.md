# Roadmap

## v0.1.0 — Local rewind

CLI, file recording, SQLite, content-addressed checkpoints, diff inspection, confirmed restores, undo, loopback UI, Tauri companion source and automated Node CI.

## v0.2.0 — Hardening

Project locking and concurrent-writer validation, retention quotas, native installers, verified 50k-file performance, genuine screenshots and stronger restore recovery tests.

## v0.3.0 — Agent integrations

Add documented hooks for individual agent products only when verified, while keeping filesystem events with unknown attribution separate from authenticated or explicitly reported agent actions.

All unreleased items are plans, not promises of implemented functionality.
