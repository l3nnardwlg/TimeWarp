# Changelog

## 0.1.0 — Development, not released

### Implemented
- pnpm/TypeScript workspace and Node built-in SQLite storage.
- Native filesystem watcher, periodic reconciliation, event sessions and local content-addressed blobs.
- Checkpoint capture, integrity verification, deduplication and garbage collection.
- Restore planning, explicit confirmation, pre-restore safety checkpoints, hash checks, progress journals, undo and manual crash recovery.
- CLI command set, JSON output and optional process wrapper.
- Token-protected loopback dashboard with timeline, diff viewer, checkpoints and restore dialog.
- React/Tauri native companion source, CI and standalone npm package staging.

### Still unverified
- Native installer artifacts, signing and notarization.
- Performance benchmarks for 50k files and 10k timeline events.
- Reliable agent-specific integrations and complete retention settings.
- Genuine product screenshots and npm publication.
